Game 01

Mine Sweeper

A native macOS SwiftUI puzzle with four complete visual themes, four board sizes, a guided lesson, keyboard and VoiceOver play, persistent records, and procedural sound. The board, feedback, icon, and sound voices are generated in code — no game engine, sprite sheet, or audio file.

4 themes · Keyboard + VoiceOver · Procedural sound · Records

Game 02

Dottie

A native macOS SwiftUI arcade maze game whose maze, sprites, and every sound are generated in code. Steer with the keyboard through a precise 28 × 31 maze while four pursuers follow distinct chase rules.

3 themes · Keyboard + VoiceOver · Procedural sound · High scores

Download Dottie Release Notes & Older Versions

macOS 14 or later · signed and notarized · updates itself.

Game 03

Tilly

A native macOS SwiftUI sliding-merge puzzle whose boards, four visual skins, and every sound are generated in code. Slide every tile as far as it can go, merge equal values from the leading edge, and build toward each board’s honest target.

4 themes · Keyboard + VoiceOver · Procedural sound · Records
